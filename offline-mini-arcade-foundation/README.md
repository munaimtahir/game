# Offline Mini Arcade — Android Foundation

Production-oriented starter scaffold for the locked MVP:

- Pulse Orbit
- Lane Drift
- Stack Drop
- Shared progression
- Daily challenges
- Local stats
- Minimal settings
- Offline-first only

This scaffold is intentionally foundation-first. It is meant to be expanded into a compiling Android Studio project with DI, real Room wiring, DataStore wiring, and the first vertical slice.
