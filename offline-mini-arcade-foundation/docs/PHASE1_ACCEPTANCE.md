# Phase 1 Acceptance Criteria

Phase 1 is accepted when:

- The project contains only the locked MVP games:
  - Pulse Orbit
  - Lane Drift
  - Stack Drop
- App starts into the arcade hub
- Navigation reaches all major routes
- Shared model layer exists
- Persistence path is defined
- No online-only dependency exists in the core architecture
- No scope drift has introduced extra games or cloud/account systems
- Foundation is ready for Pulse Orbit as the first real vertical slice
