# Lane Drift Difficulty Tuning

**Date**: May 24, 2026

## Speed Curve
- **Initial Speed**: Reduced from 142 to 110.
- **Max Speed**: Capped at 330.
- **Ramp Rate**: 3.5 per second (was 4.9).

## Spawn Rate Curve
- **Initial Interval**: 1.6 seconds (was 1.22).
- **Minimum Interval**: 0.75 seconds.
- **Ramp Rate**: 0.006 per second (was 0.0085).

This extends the early "safe" phase of the game and allows players to understand the swipe mechanic before being overwhelmed by blockers.
