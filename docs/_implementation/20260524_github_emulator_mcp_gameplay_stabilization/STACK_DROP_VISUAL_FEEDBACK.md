# Stack Drop Visual Feedback

**Date**: May 24, 2026

## Dynamic Effects
1. **Danger Glow**: A pulsing red gradient at the top of the board when blocks reach the danger zone (top 4 rows).
2. **Line Clear Flash**: A white screen-wide flash that occurs when one or more lines are cleared.
3. **Ghost Piece**: (Future implementation) Could show where the piece will land.
4. **Next Piece**: Always visible in the HUD to allow strategic planning.

## UI Components
- **Score Pill**: Shows current score.
- **Lines Pill**: Shows total lines cleared.
- **Level Info**: Difficulty level based on line count.
