# Pulse Orbit Before / After

**Date**: May 24, 2026

## Before
- **Initial Speed**: 96 (felt slightly too fast for a "first impression").
- **Initial Gap**: 82.
- **Collision**: Required orb center to be exactly within the gap. High potential for "unfair" misses.
- **Onboarding**: Static "Tap to start" text.

## After
- **Initial Speed**: 85 (more approachable).
- **Initial Gap**: 88 (more forgiving first pass).
- **Collision**: Added 4.5 degrees of tolerance. It now feels "fair" even when tapping slightly late or early.
- **Onboarding**: "Tap to start" now pulses gently to draw attention.
- **Feedback**: Added "Perfect chain" feedback and improved success/fail visual impact.
