# Pulse Orbit Visual Feedback

**Date**: May 24, 2026

## Animations
1. **Ready Pulse**: An infinite repeatable pulse on the alpha of the instruction text when the game is idle.
2. **Success Pulse**: A quick scale and color shift of the central core and ring.
3. **Ring Burst**: A radial expansion animation on "Perfect" (combo) hits.
4. **Fail Pulse**: A red screen-flash background on death.

## Text Hierarchy
- **HUD**: Score and Combo are always visible in pills at the top.
- **Badges**: "Clean timing" or "Perfect timing" badges appear during active play to reward rhythmic consistency.
