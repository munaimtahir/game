# MVP Game Specs — Offline Mini Arcade

## 1) Pulse Orbit

### Purpose
Primary hook game. Must be the fastest-to-understand and strongest first impression.

### Core loop
- orb rotates around center
- ring has opening
- player taps to burst through opening
- successful pass scores
- combo grows with clean streak
- miss causes collision and ends run

### Controls
- single tap

### Target feel
- immediate
- crisp
- highly replayable
- one-thumb friendly

### Difficulty ideas
- speed changes over time
- gap size shrinks
- ring rotation direction changes
- pattern complexity increases gradually

### Core rewards
- score
- combo
- perfect pass bonus
- survival milestone

## 2) Lane Drift

### Purpose
Provides movement-driven variety and longer flowing arcade energy.

### Core loop
- player advances forward automatically
- switch lanes to avoid blockers
- collect shard pickups
- optional combo for same-color collection or clean streak pathing
- collision ends run

### Controls
- left/right swipe or simple lane buttons
- final control method to be chosen in gameplay prototyping

### Target feel
- smooth
- readable
- fast
- “one more run”

### Difficulty ideas
- rising speed
- denser obstacles
- tighter routes
- risk-reward pickup patterns
- rush sections

### Core rewards
- distance
- pickups
- combo
- near-miss bonus

## 3) Stack Drop

### Purpose
Classic mastery game with strongest nostalgia/familiar recognition.

### Core loop
- shaped blocks descend from top
- player moves and rotates them
- complete horizontal lines to clear
- speed increases over time
- board pressure rises
- run ends when stack reaches top/spawn limit

### Controls
Recommended:
- clear on-screen buttons for left, right, rotate, and drop
Alternative gestures may be explored, but clarity is more important than novelty.

### Target feel
- familiar
- satisfying
- escalating
- strategic under pressure

### Difficulty ideas
- faster descent by level
- line-clear score bonuses
- survival milestones
- optional later twist mechanics, but not required for first prototype

### Important product rule
This mode should be inspired by the classic falling-block genre but should have its own presentation and product identity.
It must not rely on third-party branding.

## Shared integration across all 3 games

Every game should support:
- high score tracking
- session count
- challenge completion tracking
- soft currency rewards
- cosmetic theme compatibility
- fast restart
