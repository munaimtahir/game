## Current monetization decision
- Free download
- Restrained post-run interstitial ads
- Optional rewarded ads
- One-time lifetime ad removal (`premium_lifetime`)
- No subscription in the first free release
- No legacy-user migration because there are currently no real users or purchasers
- Implementation plan: `BUILD_PLANNING_NEXT_STEPS.md`
