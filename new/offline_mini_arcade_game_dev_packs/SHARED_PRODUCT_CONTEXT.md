# Shared Product Context

Project: Offline Mini Arcade

This project is a lightweight Android offline-first mini-game bundle focused on quick repeatable play.

Core product rules:
- Core gameplay must work fully offline.
- The app must remain lightweight and low-end Android friendly.
- Games must be fast to enter, fast to retry, and simple to understand.
- The arcade must feel curated, not like a random collection of clones.
- No active gameplay interruption ads.
- Each game must connect into shared high scores, sessions, daily challenges, soft currency, cosmetics/themes, and stats.
- UI should remain clean, bright, rounded, readable, and friendly.
- Avoid casino-like reward pressure, bloated screens, deceptive claims, and noisy effects.

Existing games:
- Pulse Orbit: one-tap circular timing/reflex game.
- Stack Drop: falling-block line-clear strategy game.
- Lane Drift: lane dodge-and-collect game, currently candidate for replacement.

Candidate games in this pack:
1. Brick Volley
2. Loop Snake
3. Shield Dash
4. Gravity Flip prototype
