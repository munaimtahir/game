# Game Specs MVP

This file summarizes the three locked MVP game specifications. Detailed rules live in:

- `docs/product/PULSE_ORBIT_SPEC.md`
- `docs/product/LANE_DRIFT_SPEC.md`
- `docs/product/STACK_DROP_SPEC.md`

## Pulse Orbit

- One-tap reflex timing game.
- Core loop: tap when the orb aligns with the rotating ring gap.
- Shared systems used:
  - stats
  - rewards
  - pause/resume
  - tutorial state
  - theme compatibility

## Lane Drift

- Three-lane endless dodge game.
- Core loop: swipe left or right to avoid blockers and collect pickups.
- Shared systems used:
  - stats
  - rewards
  - pause/resume
  - tutorial state
  - theme compatibility

## Stack Drop

- Original falling-block line-clear game with non-branded presentation.
- Core loop: place pieces, clear lines, survive increasing speed.
- Shared systems used:
  - stats
  - rewards
  - pause/resume
  - tutorial state
  - theme compatibility

## Scope Notes

- No fourth public MVP game exists.
- Any additional game modules present in the repository are legacy or experimental and are excluded from this spec.
